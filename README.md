# Audio Tag Analyzer

> **This project has moved to [audio-tag-analyzer-vite](https://github.com/Borewit/audio-tag-analyzer-vite).**
> Visit the new project for the current source code, documentation, and issue tracker.

This repository contains the original Audio Tag Analyzer, demonstrating [music-metadata](https://github.com/Borewit/music-metadata) running in a browser.
The [new version](https://github.com/Borewit/audio-tag-analyzer-vite) is built with React, TypeScript, and Vite.
